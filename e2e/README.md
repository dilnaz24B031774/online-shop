# E2E-тесты (Playwright) для Sauda Online Shop

Playwright сам открывает сайт в браузере, входит как `admin / Shop2026!`, кладёт «Wireless Mouse» в корзину,
оформляет заказ картой, проверяет страницы и сообщения об ошибках, а в конце отменяет заказ (товар возвращается на склад).

## Что проверяется (23 теста)

| Файл | Что делает |
|---|---|
| `tests/auth.spec.ts` | страница входа, пустая форма, неверный пароль, показать/скрыть пароль, вход и выход admin, редирект с `/cart` на логин и возврат, переключение языка RU |
| `tests/catalog.spec.ts` | каталог и цены, страница товара, поиск (найден / «ничего не найдено»), «В корзину» без входа → логин |
| `tests/cart.spec.ts` | добавить мышь, счётчик в шапке, кнопки `+` / `−`, «Удалить», добавить 2 шт. со страницы товара, корзина после перезагрузки |
| `tests/checkout.spec.ts` | **полный сценарий**: корзина → оформление → карта 4242… → «Order #N is placed and paid» → «My orders» → отмена; ошибки карты (номер, имя, срок, CVC); отклонённая карта 4000 0000 0000 0002; промокоды `FAKECODE` и `WELCOME10` (−10 % → $22.50) |

## Запуск

1. Запустите магазин как обычно (два терминала):
   - backend: `python3 manage.py runserver` (с `export POSTGRES_*`, `seed_shop` один раз)
   - frontend: `cd frontend && npm start` → http://localhost:4200
2. В третьем терминале:
```bash
cd e2e
npm install
npx playwright install chromium     # один раз, скачивает браузер
npm test                            # без окна, быстро
npm run test:headed                 # с окном браузера, медленно — удобно показывать на защите
npm run test:ui                     # интерактивный режим Playwright
npm run report                      # HTML-отчёт после прогона
```

Если сайт или backend не запущены, тесты остановятся сразу с понятным сообщением.
Другие адреса: `BASE_URL=http://localhost:4200 API_URL=http://localhost:8000/api npm test`.

## Важно знать

- Тесты идут **по одному** (`workers: 1`): у `admin` одна корзина на сервере. Перед каждым тестом корзина очищается через API.
- У `admin` в демо-данных нет адреса доставки — тест создаёт адрес «E2E Home» через API (один раз).
- У мыши в демо-данных всего 6 штук. Поэтому заказ в конце теста отменяется (и в `afterEach`, если тест упал посередине).
- Тест «неверный пароль» использует несуществующего пользователя `e2e_nobody`, чтобы не приближать `admin` к блокировке
  (5 ошибок → блок на 5 минут).
- Тест промокода `WELCOME10` требует, чтобы промокоды были в базе: `python3 manage.py seed_shop --promo-only`.
- Тексты проверяются на английском (язык сайта по умолчанию). Если команда поменяет тексты в `i18n.service.ts`,
  нужно обновить ожидания в тестах.
